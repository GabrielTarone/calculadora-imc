# Calculadora de IMC - Application Development

Projeto desenvolvido para a disciplina Application Development.

## Como executar

### 1. Clonar o repositório

git clone <https://github.com/GabrielTarone/calculadora-imc>

### 2. Entrar na pasta

cd calculadora-imc/Aula19/Introducao/Introducao

### 3. Instalar as dependências

npm install

### 4. Executar o projeto

npm run dev

Depois, acessar o endereço informado pelo Vite no terminal.
